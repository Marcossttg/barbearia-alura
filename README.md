# Barbearia Alura
![Barbearia-Alura](./img/banner.jpg)

Este é um projeto simples de uma barbearia, desenvolvido com **HTML** e **CSS**, com o objetivo de criar um site responsivo e moderno.

## 📌 Recursos

- Página inicial com informações sobre a barbearia
- Página de **produtos**, listando serviços oferecidos
- Página de **contato**, com um formulário para clientes entrarem em contato
- Design responsivo utilizando **CSS Media Queries**
- Utilização de fontes do Google Fonts para melhor estética
- Navegação intuitiva e estilizada

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
